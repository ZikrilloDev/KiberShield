CyberShield Unified Build
========================
This package merges the full CyberShield desktop/SOC application with the CIBER
animated security terminal and its extended defensive command/security engines.

Entry points:
  ciber.bat
  CIBER.bat
  CIBERSHIELD.bat
  python main.py ciber
  python main.py desktop
  python main.py terminal

Safety:
  CIBER keeps the existing safe operator allowlist. It does not execute arbitrary
  cmd.exe/PowerShell/eval text as a generic shell.
